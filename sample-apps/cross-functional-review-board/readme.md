# Cross-Functional Review Board

Team: 4Forces

## What it does
Cross-Functional Review Board is an AI-powered multi-agent enterprise decision governance system that reviews business proposals through Product, Engineering, Security, Legal, and Moderator agents.

## How to run
1. Install dependencies:
   - cd frontend && npm install
   - cd ../server && npm install
2. Start the frontend:
   - cd frontend && npm run dev
3. Start the backend:
   - cd server && npm run dev

## Notes
This app demonstrates an MCP-based multi-agent review workflow for enterprise proposal evaluation.
