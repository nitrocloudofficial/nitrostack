# 🛡️ FinSentinel: Automated Banking Fraud Investigation & Security Audit

An advanced agentic AI platform built with **NitroStack** and **NitroStudio** designed to perform comprehensive, branch-wide security audits for banking institutions, detect high-risk anomalies, and execute immediate mitigation strategies.

---

## 🚀 Key Features

*   **Automated Branch-Wide Audits:** Instantly scans customer databases and transaction patterns across specific banking branches.
*   **AI-Driven Risk Scoring:** Evaluates hundreds of accounts simultaneously, categorizing them and isolating high-risk targets with transparent AI reasoning.
*   **Interactive React Dashboard:** A deeply integrated, real-time widget preview providing visual data metrics and risk distribution graphs.
*   **Instant Containment Actions:** Enables investigators to execute security protocols (such as freezing compromised accounts or triggering automated security alerts) straight from the interface.
*   **Seamless MCP Integration:** Leverages the Model Context Protocol (MCP) to bridge local and cloud agentic workflows securely.

---

## 🛠️ Tech Stack & Architecture

*   **Core Framework:** NitroStack / Model Context Protocol (MCP)
*   **Backend:** Node.js, TypeScript
*   **Frontend UI:** React, Next.js widgets
*   **Deployment & Studio:** NitroStudio & NitroCloud

## 🚀 How to Run the Project Locally

### For Windows Users:
1. Clone the repository and open the project folder.
2. Double-click the **`start-project.bat`** file.
3. Wait for the terminal to confirm the server has started, then open the tool in **NitroStudio**.

### For Mac / Linux Users:
1. Open your terminal in the project root directory.
2. Run this single command to install, build, and start the server:
   ```bash
   npm --prefix src/widgets install && npm --prefix src/widgets run build && npm install && npm run build && npm run dev
