# GuardianSense AI

GuardianSense AI is an ambient wellness monitoring system built using ESP32 CSI and NitroStack.

## Hardware

- ESP32 DevKit V1 (CSI Sender)
- ESP32-S3 (CSI Receiver)

## Current Status

- ✅ ESP-IDF configured
- ✅ CSI Sender working
- ✅ CSI Receiver working
- ✅ Live CSI packets verified
