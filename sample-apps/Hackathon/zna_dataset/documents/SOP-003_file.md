# Standard Operating Procedure: GDPR Policy Compliance Auditing
**Document ID**: SOP-003
**Author**: Marcus Sterling (Compliance Analyst)
**Date**: 2024-04-01
**Version**: 1.0 (Active)

## Scope
This document outlines compliance audit targets for checking personal profile data across data warehouse integrations.

## Audit Rules
1. Verify that all SQL tables anonymize user details.
2. Inbound storage models must enforce 90-day retention policies under S. Mckay.
3. Compliance reports must cite audit logs as defined in GDPR audit standards.

## Rejected Alternatives
* **Manual spreadsheet verification**: Rejected as high risk and non-compliant.

## Consequences
Failures in GDPR checks will be escalated to CCO Jenkins.
