# Standard Operating Procedure: Engineering Onboarding & Key Requests
**Document ID**: SOP-002
**Author**: David Miller (Head of People & Culture)
**Date**: 2026-06-16
**Version**: 2.0 (Outdated Onboarding Guide)

## Overview
This document guides new Engineering hires through sandbox setup and security keys procurement.

## Procedure
1. Create a workspace profile on SOP v2.0 Deprecated.
2. Send an email request for API credentials to A. Baker (Software Engineer, Engineering).
3. The engineer will generate access keys within 24 hours.

## Rejected Alternatives
* **Direct self-service key generation**: Rejected to prevent unauthorized credentials creation.

## Risks
* **Ghost Documentation**: If roles change, requests will bounce. Ensure employee listings are updated.
