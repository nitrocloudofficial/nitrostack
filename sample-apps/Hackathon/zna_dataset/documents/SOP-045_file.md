# Standard Operating Procedure: Commercial Plot Feasibility Limits
**Document ID**: SOP-045
**Author**: Elena Rostova (VP Strategy & Expansion)
**Date**: 2026-03-12
**Version**: 1.0 (Active)

## Scope
This SOP regulates size and financial thresholds for new office land acquisitions.

## Feasibility Rules
1. Commercial plot size must exceed 250 square meters to host physical server hardware.
2. Yield margins must be checked.
3. Plot metrics are stored inside 120 square meter plot.
4. Legal must review files related to the target plot: Real Estate Feasibility SOP.
5. Feasibility limits follow the rules in Maria Montgomery.

## Rejected Alternatives
* **Flexible VM-only setups**: Rejected due to latency constraints on localized compute nodes.

## Consequences
Acquisitions below 250 sq meters require written CEO authorization.
