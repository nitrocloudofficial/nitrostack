Gmail MCP (NitroStack)

This folder contains a minimal NitroStack MCP implementing a Gmail search tool.

Notes:
- Environment variables required to use the Gmail API:
  - GMAIL_CLIENT_ID
  - GMAIL_CLIENT_SECRET
  - GMAIL_REFRESH_TOKEN (recommended)
  - GMAIL_REDIRECT_URI (optional)

- Install dependencies with: npm install
- Run in dev (when dependencies installed): npm run dev
