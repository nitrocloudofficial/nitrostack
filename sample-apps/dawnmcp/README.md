\# DawnMCP



A fully local, privacy-first MCP server for repository intelligence, 

persistent semantic memory, and AI agents — powered entirely by 

on-device models via Ollama, with zero cloud API calls required.



\## What it does



\- \*\*Repository Intelligence\*\*: indexes a codebase locally and answers 

&#x20; natural-language questions with grounded, file-and-line-cited responses

\- \*\*Persistent Memory\*\*: save and retrieve project context using 

&#x20; embedding-based semantic search, persisting across sessions

\- \*\*AI Agents\*\*: plan tasks, review code, and debug issues by reasoning 

&#x20; over the actual indexed codebase



\## Stack



TypeScript, NitroStack, Ollama (qwen2.5-coder:7b + nomic-embed-text), ChromaDB
