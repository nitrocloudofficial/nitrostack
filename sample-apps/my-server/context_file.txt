16) NitroCloud deployment error investigation and OAuthModule fix
-----------------------------------------------------------------
- User reported NitroCloud startup logs:
  - Widget registry loaded
  - Application initialized
  - Error: `Failed to instantiate provider "class OAuthModule ..."`
- Investigation details:
  - Root app was not directly importing NitroStack `OAuthModule`.
  - NitroStack runtime eagerly resolves registered modules/providers during `server.start()`.
  - Dynamic modules such as `OAuthModule.forRoot(...)` must provide required config/dependencies.
  - Installed SDK docs/template showed correct syntax:
    - `OAuthModule.forRoot({ resourceUri, authorizationServers, ... })`
- Modified:
  - `src/app.module.ts`
- Added explicit NitroStack OAuth module wiring:
  - `OAuthModule.forRoot({ ... })`
  - `required: process.env.OAUTH_REQUIRED === 'true'`
  - `resourceUri`: `RESOURCE_URI` or `NITROSTACK_PUBLIC_URL` or fallback `https://mcplocal`
  - `authorizationServers`: `AUTH_SERVER_URL` or fallback `https://github.com`
  - `scopesSupported`: `repo`, `read:user`
  - HTTP config from `PORT`, `HOST`, `MCP_BASE_PATH`
  - Optional verifier config:
    - `JWKS_URI`
    - `INTROSPECTION_ENDPOINT`
    - `INTROSPECTION_CLIENT_ID`
    - `INTROSPECTION_CLIENT_SECRET`
    - `TOKEN_AUDIENCE`
    - `TOKEN_ISSUER`
- Important distinction clarified:
  - NitroStack OAuth protects/exposes the MCP server.
  - GitHub OAuth obtains a GitHub API access token for repository operations.

- Added browser OAuth session tracking:

  - status: `pending | authenticated | error`
  - expires after 10 minutes
- Added methods:
  - `startBrowserAuthorization(redirectUriOverride?)`
    - builds GitHub `/login/oauth/authorize` URL
    - generates secure random `state`
    - stores pending session
    - requires `GITHUB_OAUTH_CLIENT_ID`
    - requires `GITHUB_OAUTH_CLIENT_SECRET` for browser redirect flow
  - `completeBrowserAuthorization({ state, code, error, errorDescription })`
    - validates state
    - exchanges GitHub callback `code` for access token
    - stores token in `runtimeToken`
    - fetches authenticated user
  - `pollBrowserAuthorization(state)`
    - returns pending/authenticated/error status to the MCP client
  - `getBrowserRedirectUri()`
    - uses `GITHUB_OAUTH_REDIRECT_URI`
    - otherwise builds from `RESOURCE_URI` or `NITROSTACK_PUBLIC_URL`
    - callback path: `/auth/github/callback`
