WARDEN·MCP Tool Reference & Judge Demo Guide
Amrita MCP Hackathon 2026 · Open Innovation

Every tool WARDEN exposes, what it's for, and proof it runs

WARDEN is a threat-intelligence MCP server built on the NitroStack CLI framework. It scans dependency manifests and live websites for real vulnerabilities, ranks them by actual exploitation evidence instead of raw CVSS, generates and verifies patches, and reads threat-intel reports without letting a hostile page hijack the agent reading them.

This page covers all 20 tool primitives across 9 modules — 18 labeled TOOL and 2 labeled TASK in NitroStudio's own graph view. Both labels come from the identical @Tool decorator in source — NitroStudio's UI groups generate_patch and fingerprint_technology differently for display, not because they're a different MCP primitive.

How to validate a tool in NitroStudio:
  1. Open this project in NitroStudio (or run npm start) and open the tool graph.
  2. Click the tool card that matches the name below.
  3. Paste the Sample input JSON from that tool's panel into NitroStudio's invoke/test panel and run it.
  4. Compare what comes back against Captured output — every result on this page was captured from a real run of this exact build, not hand-written.
