# Security Policy

## Supported Versions

Currently, only the latest version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainers privately rather than opening an issue. All security vulnerabilities will be promptly addressed.
