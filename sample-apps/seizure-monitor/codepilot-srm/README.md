## 📖 Overview

**CodePilot SRM** is designed to help SRM students prepare for coding interviews. Instead of just providing a list of questions, this platform offers personalized AI mentorship, progressive hinting, and curated roadmaps to build real problem-solving skills and intuition for Data Structures and Algorithms (DSA).

## ✨ Key Features

- **Personalized Mentorship**: Get question recommendations based on topic, difficulty, and your personal progress.
- **Concept First**: Explains intuition, brute-force, and optimized approaches before revealing code.
- **Progressive Hints**: Provides structured, step-by-step hints without giving away the complete answer immediately.
- **Dynamic Roadmaps**: Generates personalized DSA learning roadmaps tailored to your weaknesses and goals.
- **Mock Interviews**: Interactive mock interview sessions to test your knowledge under pressure.

## 🛠️ Architecture & Modules

The application leverages the **NitroStack MCP Architecture**, utilizing a powerful **Mentor Module** to drive the AI interactions. The module exposes the following core tools:

- 🔍 `recommend_questions`: Recommends curated questions based on your skill level and progress.
- 👨‍🏫 `teach_concept`: Breaks down complex problems and teaches the underlying intuition and complexity.
- 💡 `generate_hints`: Offers progressive hints for any given problem.
- 🗺️ `generate_roadmap`: Creates a customized, topic-based DSA learning roadmap.
- 🎯 `start_mock_interview`: Initiates an interactive, FAANG-style coding mock interview.

## 🚀 Quick Start

Ensure you have Node.js (v20+) and npm installed, then run the following commands to get started:

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

## 💻 Common Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Starts the NitroStack development server. |
| `npm run build` | Builds the project for production. |
| `npm start` | Runs the built production server. |
| `npm run widget` | Starts the UI widgets development server. |
