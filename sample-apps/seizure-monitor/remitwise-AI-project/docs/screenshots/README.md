# RemitWise AI – Application Screenshots & UI Media

This directory stores visual assets and screenshots demonstrating the RemitWise AI application interface.

## Visual Highlights

1. **Live Exchange Rate Ticker**: Real-time ticker bar showcasing live FX rate fluctuations.
2. **Provider Comparison Grid**: Comparative matrix ranking Wise, Remitly, Western Union, Revolut, and OFX.
3. **Timing Confidence Meter**: AI-driven recommendation widget indicating optimal transfer windows.
4. **Savings Counter**: Dynamic calculator highlighting user savings achieved per corridor.
5. **Compliance Verification Modal**: KYC document checklist and corridor limit checker.
