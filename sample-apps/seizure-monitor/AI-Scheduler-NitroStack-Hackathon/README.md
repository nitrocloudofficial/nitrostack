# 🤖 AI Scheduler

An intelligent productivity assistant that goes beyond traditional to-do lists by using AI to automatically schedule tasks, dynamically adapt to changes, and help users manage their day.

Built for a **24-hour Hackathon**, AI Scheduler demonstrates how Agentic AI can simplify everyday planning while integrating seamlessly with Google Calendar.

---

## ✨ Features

### 📅 Intelligent Task Scheduling

* AI-powered task scheduling based on priority and duration
* Automatic conflict detection
* Calendar-aware planning
* Smart time allocation

### 🔄 Dynamic Rescheduling

* Automatically reorganizes your schedule when:

  * Meetings are added
  * Tasks are delayed
  * Deadlines change
  * Unexpected events occur

### 📊 Productivity Dashboard

* Daily analytics
* Task completion tracking
* Focus time monitoring
* Productivity insights

### ✅ Habit Tracker

* Track daily habits
* Visual progress indicators
* Consistency monitoring

### 💰 Expense Tracker

* Record expenses
* Categorize spending
* Monitor financial habits

### 📆 Google Calendar Integration

* Sync events automatically
* Read existing calendar events
* Create and update schedules
* Prevent scheduling conflicts

---

# 🧠 How It Works

1. The user provides tasks using text or voice.
2. The AI analyzes:

   * Task priority
   * Estimated duration
   * Calendar availability
   * Existing commitments
3. The scheduling engine generates an optimized daily plan.
4. If new events or delays occur, the assistant dynamically reschedules remaining tasks.
