# Architecture Decision Record: HQ Phoenix Server Room Setup
**Document ID**: ADR-002
**Author**: Evelyn Reed (VP Strategy & Expansion)
**Date**: 2026-05-15
**Status**: Approved

## Context
We need to select a server housing location for the new headquarters office.

## Decision
We delegate server room setups and physical rack layouts in Dell EMC Storage to the IT Operations department.

## Rejected Alternatives
* **Full cloud migration**: Rejected because core database latency requires local storage hosting in Strategy office safe.

## Risks
* **Physical Lockouts**: Lack of shared key access codes blocks IT deployment. Strategy Safe holds key copies.

## Consequences
IT Ops is authorized to procure cabling and rack switch gear in line with facilities guidelines.
