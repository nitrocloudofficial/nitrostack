# NitroStack CCTV Analyzer

This project is a NitroStack CCTV analyzer app with interactive event widgets.
It demonstrates how to connect a NitroStack MCP tool to a widget front-end.

## What This Project Includes

- A CCTV event search tool backed by sample event data
- A widget that renders CCTV incident feed data
- NitroStack module, service, and tool patterns
- A widget manifest for runtime widget registration

## Quick Start

```bash
npm install
npm run dev
```

## Common Commands

```bash
npm run dev
npm run build
npm start
npm run widget <command>
```
