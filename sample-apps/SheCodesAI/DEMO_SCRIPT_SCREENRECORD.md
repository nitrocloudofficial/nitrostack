# ContextOS - Screen Recording & Video Demo Guide

> **Project**: ContextOS — Adaptive AI Context Intelligence Platform
> **Tagline**: *"One Conversation. Infinite Intelligent Workflows."*
> **Presenter**: Haswitheswari KamboJi (Lead AI Engineer) & Team of 4

This document provides a step-by-step narration script and action timeline for creating a **winning screen recording video demo** of ContextOS.

---

## 🎬 Video Recording Plan & Script (Duration: 3 - 5 Minutes)

### Phase 1: Landing Page & Problem Statement (0:00 - 0:45)
- **What to show on screen**: Open `http://localhost:3000` (Landing Page).
- **Narration Script**:
  > *"Hello everyone! Welcome to ContextOS — an Adaptive AI Context Intelligence Platform built for modern enterprise teams. ContextOS transforms live meetings, transcripts, and documents into structured documentation, Jira tickets, Notion knowledge bases, and ChromaDB vector memory.*
  > 
  > *Unlike generic meeting summarizers that try to auto-classify and hallucinate, ContextOS strictly enforces Manual Context Selection. The transcript stays constant — but the generated workflow transforms according to the selected Context Pack."*

---

### Phase 2: Live Processing & Interactive Uploads (0:45 - 1:45)
- **What to show on screen**: Click **"Launch ContextOS Engine"** or navigate to **AI Room & Processor**.
- **Actions**:
  1. Click **"Uploaded Text"** under Input Source → Show the **interactive textarea** with meeting transcript.
  2. Click **"Audio File"** or **"Document"** → Show the file upload dropzones (`.wav`, `.mp3`, `.pdf`, `.docx`).
  3. Show the **Manual Context Pack Picker** on the left (highlight *Software Development*, *Healthcare*, *Business*, *Hackathon*).
  4. Click **"Run AI Processing Pipeline"**.
  5. Point out the **Live AI Reasoning Panel** animating through all 10 stages: *Reading Transcript → Extracting Tasks → Detecting Deadlines → Completed*.

---

### Phase 3: Human Approval Cards & MCP Execution (1:45 - 2:45)
- **What to show on screen**: Scroll to **Human Approval Cards** section.
- **Actions**:
  1. Highlight Task #101 assigned to **Haswitheswari KamboJi** (*Deploy FastAPI Auth Microservice*).
  2. Highlight the confidence score (`96%`) and target tool (`GitHub`).
  3. Click **"Approve & Trigger MCP"**!
  4. Point out the status badge changing to `APPROVED (MCP Executed)`.

---

### Phase 4: Visual MCP Workflow Canvas (Node 1 to Node 7) (2:45 - 3:45)
- **What to show on screen**: Click **"Visual Workflow (MCP)"** in the sidebar.
- **Actions**:
  1. Show all 7 nodes connected horizontally:
     - **Node 01**: Input Transcript Stream
     - **Node 02**: Context Pack Engine (Software Dev)
     - **Node 03**: AI Reasoning & Task Extractor
     - **Node 04**: Human Approval Gate (Completed!)
     - **Node 05**: MCP Router & Orchestrator (Active & Executed!)
     - **Node 06**: Notion Knowledge Hub Sync (Completed!)
     - **Node 07**: ChromaDB Memory Update (1,536-dim vectors indexed!)
  2. Click on different nodes to show the **Node Inspector** and **Real-Time Node Terminal Stream** updating dynamically.

---

### Phase 5: Notion Knowledge Hub & Vector Inspector (3:45 - 4:30)
- **What to show on screen**: Click **"Knowledge Hub (Notion)"** and **"ChromaDB Vector Inspector"**.
- **Actions**:
  1. In Knowledge Hub: Perform a semantic search for *"FastAPI Auth"*, show architectural decision checklists, and click **Versions** to open the version history modal.
  2. In Vector Memory Inspector: Type a query in the **Interactive Vector Similarity Search** box and click **Compute Similarity** to show live 1,536-dimensional cosine matching!

---

### Phase 6: Conclusion & Backend Verification (4:30 - 5:00)
- **What to show on screen**: Show **Workspace & Security** page with **Haswitheswari KamboJi (Team of 4)** and the security audit log.
- **Narration Script**:
  > *"ContextOS bridges human conversation and autonomous workflow execution with full enterprise security, human control, and zero auto-classification errors. Thank you for watching!"*

## 📽️ Recommended Recording Tools & Settings

- **Recording Software**: OBS Studio / Loom / Windows Game Bar (`Win + Alt + R`).
- **Resolution**: 1080p (1920 x 1080) at 60 FPS.
- **Microphone**: Set input volume clean without background noise.
