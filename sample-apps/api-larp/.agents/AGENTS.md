# Agent Rules for api-larp

## Hackathon / Feature Intent Interpretation

When a user working on a project asks "can I use X instead of Y?" or "I have key X, can I use it?":
- Treat it as a **feature request** to add support for X, not a capabilities question.
- Do not just answer yes/no — confirm: "You have X key — do you want me to add X support?"
- Especially applies to LLM providers, API keys, and authentication methods.
- Example: "Can I use a Gemini key?" → ask "Do you want me to add Gemini as a supported LLM provider?"
