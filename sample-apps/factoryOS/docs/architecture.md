# FactoryOS Architecture Document

## Overview

FactoryOS is an enterprise platform integrated with NitroStack MCP Server, custom widgets, Express API backend, and Next.js frontend UI.

## Components

- **`src/`**: Official NitroStack MCP Server powering tools, resources, and prompts.
- **`widgets/`**: Interactive UI widgets rendered directly inside LLM chat interfaces.
- **`frontend/`**: Web application for Customer and Admin management.
- **`backend/`**: Express REST API service for traditional endpoints.
- **`shared/`**: Common TypeScript interfaces, types, constants, and utilities.
