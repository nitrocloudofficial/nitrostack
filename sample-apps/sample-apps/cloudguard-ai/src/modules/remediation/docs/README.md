# CloudGuard AI 🛡️

Autonomous FinOps and Security Remediation Platform built on NitroStack.

## Features
* **168-Hour Metric Classification:** Detects zombie waste without killing nightly ETL batch jobs.
* **Non-Destructive IaC Generation:** Generates dry-run Terraform plans for security findings.
* **Human-in-the-Loop Governance:** Enforces mandatory human approval guardrails before any remediation workflow executes.

## Quickstart

```bash
# Install dependencies
npm install

# Run full end-to-end pipeline test
npm run dev
